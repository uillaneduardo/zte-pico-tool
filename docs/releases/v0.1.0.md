# Release v0.1.0 — H3601P Activity Monitor

**Status:** experimental / hardware investigation

## Objetivo

Primeira firmware do `zte-pico-tool`, criada para observar passivamente os pads 2 e 3 identificados na placa do ZTE H3601P.

## Funcionalidades

- Monitoramento digital de `GP2` e `GP3`.
- Contagem de bordas de subida e descida.
- Estado lógico atual de cada entrada.
- Captura automática de 5 segundos.
- Monitoramento contínuo.
- Interface de comandos via USB CDC.
- Modo estritamente passivo em relação ao H3601P.

## Comandos

```text
?  ajuda
s  estado atual
r  zerar contadores
m  monitorar por 5 segundos
c  monitorar continuamente
```

## Pinagem experimental

```text
ZTE pad 2 -> Pico GP2
ZTE pad 3 -> Pico GP3
ZTE pad 4 -> Pico GND
ZTE pad 1 -> NÃO CONECTAR
```

O pad 4 foi confirmado como GND com multímetro. Os pads 1–3 apresentaram aproximadamente 3,3 V em repouso, mas a função de cada pad ainda não foi confirmada.

## Limitações

Esta versão não é um analisador lógico completo e não decodifica UART. Os contadores de transição são usados somente como evidência inicial de atividade.

Não há suporte a:

- transmissão para o ZTE;
- UART bridge;
- SPI;
- SPI-NAND;
- leitura de flash;
- escrita de flash;
- alteração de firmware;
- recuperação do equipamento.

## Segurança elétrica

O pad 1 não deve ser conectado ao Pico. Não conectar a alimentação do Pico à placa do ZTE. Antes de evoluir para comunicação ativa, confirmar os níveis elétricos e a função dos pads.

## Como obter o firmware

O código-fonte desta release está em:

`firmware/pico/activity_monitor/activity_monitor.ino`

A compilação é feita com o core Arduino-Pico (Earle Philhower). O artefato UF2 deve ser gerado pelo ambiente de compilação correspondente à placa exata do usuário.
